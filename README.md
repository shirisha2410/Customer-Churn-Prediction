# Customer Churn Prediction

## Project Overview
This project predicts whether a customer is likely to churn using Machine Learning.

## Features
- Gender
- Age
- Senior Citizen
- Tenure Months
- Contract
- Internet Service
- Payment Method
- Monthly Charges
- Support Calls

## Machine Learning Model
- Logistic Regression
- StandardScaler for feature scaling
- LabelEncoder for categorical features

## Deployment
The prediction application is built using Streamlit.

## Project Files
- app1.py – Streamlit application
- churn_model.pkl – Trained machine learning model
- scaler.pkl – Feature scaler
- label_encoders.pkl – Categorical encoders
- feature_columns.pkl – Feature column order

## Objective
To predict customer churn and help businesses identify customers who may leave their service
